# 마이약장 상태 필터 (2026-10-22)

기존 약장 API 응답을 이용하므로 BE·AI 변경이나 DB 마이그레이션은 없다.

| 필터 | 표시 기준 |
|---|---|
| 모든 상태 | 기존 제품 탭·검색 조건에 맞는 모든 항목 |
| 주의 성분 | 성분 가이드 warnings가 하나 이상인 항목 |
| 성분 겹침 | 현재 약장에 남아 있는 다른 등록 항목과 성분이 겹치는 항목 |
| 정보 미확인 | 가이드 상태가 AVAILABLE이 아닌 항목. PARTIAL·미등록·누락·구버전 응답 포함 |

정보 미확인과 주의 성분은 동시에 해당할 수 있다. AVAILABLE은 가이드 연결 상태이며 안전 판정이 아니다.
제품 탭·검색어·상태 필터는 함께 적용한다. 겹침 여부는 필터링 전 전체 약장을 기준으로 비교한다.
삭제 후 상대 제품이 사라지면 성분 겹침 필터에서도 제외한다.
‘검색·상태 필터 초기화’는 검색어와 상태 필터만 초기화하고 제품 탭은 유지한다.
빈 약장과 조건에 맞는 항목이 없는 경우는 구분한다.

검증: 가이드·약장 관련 Flutter 테스트 17개 통과, 변경 코드 정적 분석 오류 없음.

## 팀원 B 기준 남은 필수 작업

1. 실제 제품 데이터로 대표 5개 성분 연결 확인. 이전 점검에서 미연결이었던 모르핀은
   공식 품목 후보를 확보했으나 A와 수집·반영 기준 확정 및 실제 약장 표시 확인이 남아 있다.
2. A의 성분 정규화·중복 연결·첨가제 정리 후 별칭 매칭 재검증.
3. 시연 제품의 최신 국내 허가사항과 가이드 문구 대조 및 시연 제품 확정.
4. C의 준비 이미지/품목 매핑이 준비되면 이미지 인식 → 확인 → 등록 → 경고 표시 통합 시연.
5. 실제 브라우저/모바일에서 작은 화면, 긴 문구, 등록·삭제·필터 흐름을 직접 확인.

초기 B 범위의 가이드·경고·기능별 자동 테스트는 구현되어 있다.
복용량 합산, 실제 과량 판정, 복용 이력 기반 의존성 판정, 푸시 알림은 초기 범위의 필수 미완료 항목이 아니다.
현재 우선순위는 추가 기능보다 위 데이터 검증과 통합 시연이다.
